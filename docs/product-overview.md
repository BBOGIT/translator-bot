# Translator Bot — огляд продукту

**Дата оновлення:** 2026-04-23  
**Аудиторія:** бізнес-аналітики, клієнти, нові члени команди

---

## Що це за продукт

**Translator Bot** — це інструмент для вивчення англійської лексики всередині Telegram. Складається з двох частин:

1. **Telegram-бот** — текстовий чат-бот із кнопками і командами
2. **Mini App** — повноцінний веб-застосунок всередині месенджера (відкривається як екран в Telegram без виходу з додатку)

Обидві частини підключені до одного сервера та бази даних, тому зміни в одному місці одразу відображаються в іншому.

---

## Для кого

Люди, які вивчають англійську мову і хочуть:
- Зберігати нові слова "по ходу" — прямо з телефону, не перемикаючись між додатками
- Не забувати вивчені слова завдяки автоматичним нагадуванням
- Бачити, скільки слів вже вивчено і яка динаміка

## Ключові функції

### 1. Додавання слів

**Через бота (чат):**
Користувач пише слово → бот автоматично робить переклад та генерує приклади речень через AI (OpenAI або Deepseek). Слово зберігається в персональному словнику.

**Через фото:**
Користувач надсилає фото тексту → AI розпізнає слово і перекладає його.

**З Telegram-каналів (автоматично):**
Якщо переслати пост з навчального каналу (наприклад, "English by Films") — бот сам витягне слово, переклад і приклади. При першому повідомленні з нового каналу AI аналізує його формат і запам'ятовує — всі наступні пости обробляються миттєво без звернення до AI.

### 2. Повторення слів (Spaced Repetition)

Система автоматично нагадує повторити слово через зростаючі проміжки часу: **1 → 3 → 7 → 14 → 30 → 90 днів**. Після 6 успішних повторень слово вважається вивченим.

- Щодня в зручний для користувача час (за замовчуванням 20:00) приходить нагадування
- Час можна змінити через налаштування
- Якщо слово ще важке — інтервал скидається на початок

### 3. Mini App (веб-застосунок у Telegram)

Відкривається кнопкою прямо в чаті. Надає зручніший візуальний інтерфейс для всіх тих же функцій:

| Екран | Що робить |
|-------|-----------|
| **Home** | Дашборд: статистика, смуга прогресу, стрик-дні, ярлики до дій |
| **Learn** | Додати нове слово — поле вводу + кнопка "Translate", результат із прикладами |
| **Repeat** | Флешкарти для повторення: показує слово → перевертається → переклад і приклади |
| **Practice** | Режим тренування: список слів із можливістю перегляду в режимі картки |
| **Progress** | Кругова діаграма прогресу, тижневий графік активності, лічильники |
| **Words** | Список всіх вивчених слів із пошуком і акордеоном прикладів |
| **Schedule** | Налаштування часу щоденних нагадувань (пресети або кастомний час) |
| **Settings** | Час нагадування, вмикання/вимикання сповіщень, посилання до розділів |

## Технічна архітектура (для BA)

```
Telegram App
  ├── Чат-бот (команди, кнопки, state machine)
  └── Mini App (Angular 18, відкривається в WebView)
            ↓
       NestJS Backend (API + логіка)
            ↓
       PostgreSQL (слова, користувачі, налаштування)
            ↓
       AI Provider (OpenAI або Deepseek — перекладає, генерує приклади)
```

**Аутентифікація Mini App:** Telegram автоматично передає підписаний токен користувача при відкритті — окремої реєстрації/логіну не потрібно.

## Технічний стек

- **Backend:** NestJS (Node.js), PostgreSQL, Prisma ORM
- **Frontend:** Angular 18, NgRx state management
- **AI:** OpenAI GPT / Deepseek (конфігурується через змінну середовища)
- **Інфраструктура:** Docker, монорепозиторій (backend + frontend в одному repo)
- **Авторизація:** JWT токени, Telegram initData HMAC-SHA256
