# Автовитяг слів з Telegram-каналів

**Статус:** Реалізовано (вересень 2025)  
**Дата оновлення:** 2026-04-23

---

## Що це і навіщо

Функція дозволяє користувачу **переслати пост з будь-якого навчального Telegram-каналу** — бот автоматично розпізнає слово, переклад і приклади речень та зберігає їх у словнику. Не потрібно нічого вводити вручну.

Наприклад, популярні канали типу "English by Films" публікують пости у форматі:
```
😼 genuine - підлинний; справжній; щирий

1️⃣ Not genuine.
   Не справжній.

2️⃣ Do you believe that Hal has genuine emotions?
   Ви вірите, що у Хела є щирі емоції?
```

Користувач просто пересилає такий пост боту — і слово одразу в словнику.

---

## Як це працює

### Бізнес-процес (кроки для користувача)

1. Знайти цікавий пост із новим словом у Telegram-каналі
2. Переслати пост боту
3. Отримати підтвердження: бот відповідає з витягнутим словом і перекладом
4. Слово одразу доступне для повторення

### Технічний процес (один раз на новий канал)

При **першому** повідомленні з нового каналу:
- Бот аналізує формат поста через AI
- AI генерує набір regex-паттернів, що описують структуру постів цього каналу
- Паттерни зберігаються в базі даних

При **всіх наступних** повідомленнях з того ж каналу:
- Паттерни беруться з БД — AI не викликається
- Витяг відбувається миттєво

### Схема потоку

```
Пересланий пост → WebhookService (визначає forward_origin)
                → ChannelExtractionService (перевіряє БД)
                    ├── Конфіг є → застосовує regex → зберігає слово
                    └── Конфіг нема → AI генерує паттерни → зберігає → застосовує → зберігає слово
                → Підтвердження користувачу
```

---

## Що витягується

З кожного поста бот витягує:
- **Слово** (англійське)
- **Переклад** (всі варіанти через крапку з комою)
- **Приклади речень** (пронумеровані блоки з перекладом)

---

## Переваги підходу

- **Один раз на канал** — AI платний, тому паттерни кешуються в БД
- **Гнучкість** — паттерни можна відредагувати вручну в БД, якщо канал змінив формат
- **Надійність** — є fallback на загальні паттерни, якщо AI недоступний
- **Масштабованість** — легко підтримує будь-яку кількість каналів

## Технічні компоненти

| Файл | Призначення |
|------|-------------|
| `src/channel/channel-extraction.service.ts` | Основна логіка витягу даних |
| `src/bot/handlers/forwarded/forwarded-message.handler.ts` | Обробник пересланих повідомлень |
| `src/webhook/webhook.service.ts` | Визначення типу повідомлення (forward_origin) |
| `src/ai/ai.service.ts` | Метод `generateRegexPatterns()` |

**Таблиця БД:** `channel_extraction_configs` — зберігає `channelId`, regex-паттерни, прапор `createdByAI`.

## Плани розвитку

- API для управління конфігураціями каналів (перегляд, редагування, тест паттернів)
- Статистика успішності витягу по каналах
- Попередній перегляд витягнутих даних перед збереженням
- Можливість позначити слово як "вже знаю" одразу при витягу
