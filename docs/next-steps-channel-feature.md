# Беклог: розвиток функції витягу з каналів

**Останнє оновлення:** 2026-04-23

---

## Що вже реалізовано (Етап 1)

- Автовитяг слова, перекладу та прикладів з пересланих постів
- AI-генерація regex-паттернів при першому повідомленні з каналу
- Збереження паттернів у БД (повторні повідомлення без AI)
- Підтвердження користувачу після збереження

---

## Наступні кроки (Етап 2 — в планах)

### Управління каналами (Високий пріоритет)

Потрібно додати API endpoints для адміністрування:
```
GET    /api/channels              — список всіх каналів із паттернами
GET    /api/channels/:id          — деталі конфігурації
PUT    /api/channels/:id          — оновити паттерни вручну
DELETE /api/channels/:id          — видалити конфігурацію
POST   /api/channels/:id/test     — протестувати паттерни на прикладі тексту
```

### Статистика (Середній пріоритет)

- Кількість успішних/невдалих витягів по кожному каналу
- Дашборд активності (скільки слів додано через канали vs вручну)

### Покращення UX (Середній пріоритет)

- Попередній перегляд витягнутих даних перед збереженням слова
- Можливість редагувати слово/переклад до збереження
- Категоризація слів за джерелом (канал vs ручний ввід)

### Покращення AI (Низький пріоритет)

- Автоматичне оновлення паттернів при зміні формату каналу
- Confidence scoring — оцінка якості витягнутих даних
